# 📊 DroneAdmin Dashboard

DroneAdmin Dashboard is a modern, responsive **Admin Dashboard Web App** built with HTML, CSS, and JavaScript. It allows administrators to monitor **sales, orders, customers, recent updates, and analytics** in a clean and interactive UI. The project includes **dark/light mode**, dynamic order rendering from JavaScript, and responsive layouts optimized for desktop and mobile devices.

This project serves as a lightweight **frontend-only admin panel**, ideal for showcasing dashboard UI/UX skills, practicing DOM manipulation, and building real-world inspired layouts.

## ✨ Features

- **Responsive Layout** – Optimized for mobile, tablet, and desktop.
- **Side Navigation Menu** – Expandable and collapsible sidebar.
- **Dark \& Light Theme** – Built-in theme toggler with logo and text color changes.
- **Dynamic Order Rendering** – Orders automatically load from `orders.js`.
- **Analytics \& Insights** – Visual sections for sales, expenses, and income.
- **Recent Orders Table** – Displays product name, order ID, payment status, and shipping state.
- **Recent Updates Section** – List of recent activities and customer updates.
- **Sales Analytics Section** – Highlights online, offline, and customer growth.
- **Smooth CSS Animations** – Transitions, hover states, cards, and shadows for modern UI feel.

***

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Data Storage:** Static JavaScript object (`orders.js`)
- **Fonts:** Google Fonts (Poppins, Jost, Martel Sans)
- **Icons:** Font Awesome / Inline SVGs
- **Design System:** CSS Grid, Flexbox, CSS Variables

## 📝 Installation \& Setup

📌 This is a **frontend-only project**, so you don’t need Node.js or a backend server.

### Steps:

1. **Clone the Repository**

```bash
git clone https://github.com/YourUsername/AdminDashboard.git
cd AdminDashboard
```

2. **Open in Browser**
You can simply open `index.html` in your browser.
3. *(Optional for Dev Server)* Use **Live Server Extension** in VS Code for auto-refresh:
    - Right-click `index.html` → "Open with Live Server".

## 📦 Project Highlights

- **Theme Switcher:** Users can toggle between **light \& dark mode**, and logo/slogan colors update accordingly.
- **Dynamic Table Data:** The `orders.js` file contains all sample order data for rendering order records dynamically.
- **Modern Dashboard Layout:** A 3-column responsive grid: sidebar (navigation), main content (insights \& orders), right column (updates \& analytics).
- **Mobile Responsive Design:** Sidebar collapses into a toggleable drawer on smaller screens.
- **Reusable UI Components:** Cards, grids, tables, and flex-based layouts for consistent design.
